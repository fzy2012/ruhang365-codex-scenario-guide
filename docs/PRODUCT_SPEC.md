# 产品规格：Codex 场景导航器

## 可验收目标

一个第一次使用 Codex 的用户，只输入一句“我想做什么”，就能在一分钟内知道从哪里开始、复制什么任务描述，以及如何判断结果是否成功。

## 目标用户

- 第一次使用 Codex 的非技术用户；
- 知道业务目标，但不知道该选择 Quick Chat、Project、Codex 或插件的人；
- 已经尝试过，但被权限、资料范围、任务描述或结果判断卡住的人。

## 核心路径

```text
描述场景
→ 推荐入口
→ 查看分步操作
→ 复制任务描述
→ 执行并判断成功
→ 失败时恢复
```

## V1 用户验收

1. 用户可以输入自然语言，也可以浏览场景卡片。
2. 每个场景只给一个默认入口，并说明原因。
3. 每个场景提供可直接复制的任务描述。
4. 用户能看到明确成功结果和失败恢复。
5. 用户不需要理解内部路由、模型或 Skill。
6. 更新提示只显示经过人工确认的内容。

## 更新协议

```text
OpenAI 官方 Codex Changelog
→ 官方 RSS 条目指纹变化
→ 列出新增、修改或移除的条目
→ 生成 pending_review 候选
→ 关键词仅建议可能受影响场景
→ 人工判断真实影响、适用范围与操作变化
→ 修改场景内容
→ 验证后发布
```

变化检测和关键词匹配都不能证明功能对所有套餐、地区和工作区均可用，也不能直接证明现有指南必须修改；场景内容必须经过人工核验并保留适用范围。

## 非目标

- 官方文档镜像；
- 自动发布新闻流；
- 通用 AI 聊天机器人；
- 一次覆盖桌面端、CLI、IDE 和 Cloud；
- 复杂内容管理后台。
